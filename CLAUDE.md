# ai-tools

Monorepo di dashboard interne (React + Hono + D1) su un unico Worker Cloudflare. Chi lavora qui spesso non programma: spiega in italiano semplice.

Prima di modificare qualsiasi cosa leggi la skill `architettura-dashboard` (`.claude/skills/`). Stack frontend obbligatorio (Emotion, React Router, Redux Toolkit/RTK Query): `stack-frontend`. Per creare una dashboard: `nuova-dashboard`; per il database D1: `database-d1`; per leggere dati da MongoDB: `mongodb-proxy`; per pubblicare: `deploy-dashboard`.
